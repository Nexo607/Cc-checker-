# NEXO Full Sandbox Terminal

Full GUI representation of the supplied workflow, implemented as an authorized sandbox simulator.

Included:
- Tools/workflow panels
- Login/form-key simulation
- Address extraction simulation
- Hosted-payment iframe/uID simulation
- Request counter
- Retry simulation
- Proxy/IP status simulation
- Response parser
- JSON/debug console
- Approved/declined/error scenarios
- Mobile/iPhone responsive UI
- FastAPI backend
- React/Vite frontend
- Docker deployment

Safety:
This build intentionally does not accept or transmit real PAN/CVV data and does not connect to a live merchant/payment processor. Use an official provider sandbox and tokenized test values for real integration testing.
